# Trash Detection and Classification

This project provides scripts and utilities for cleaning, processing, visualizing, and validating object detection datasets in COCO format, specifically for trash detection and classification tasks.

## Project Structure

- `src/` - Source code for data cleaning, conversion, visualization, and validation.
- `data/` - Contains images and annotation files.
- `annotations_clean.json` - Cleaned COCO annotations generated by `clean.py`.
- `best.pt` - YOLO model weight.

## Main Scripts

### 1. Data Cleaning

[`src/clean.py`](src/clean.py)  
Cleans the original COCO annotations by:
- Removing invalid or out-of-bounds bounding boxes.
- Dropping images with no valid annotations.
- Pruning unused categories.
- Saving the cleaned annotations to `annotations_clean.json`.

**Usage:**
```sh
python src/clean.py
```

### 2. Data Visualization

[`src/visualise.py`](src/visualise.py)  
Randomly samples images and overlays bounding boxes for visual inspection.

**Usage:**
```sh
python src/visualise.py
```

### 3. Data Parsing & Statistics

[`src/parser.py`](src/parser.py)  
Prints dataset statistics and category distributions.

**Usage:**
```sh
python src/parser.py
```

### 4. Training the YOLO model

[`src/val.py`](src/model.py)  
Imports and trains the YOLO model on your custom dataset.

**Usage:**
```sh
python src/val.py
```
### 5. Validation with YOLO

[`src/val.py`](src/val.py)  
Runs inference on the validation set using a trained YOLO model and saves annotated predictions.

**Usage:**
```sh
python src/val.py
```

## Data Preparation

- Place your raw images in `data/Images/`.
- Place your original COCO annotation file as `data/annotations.json`.
- Run `clean.py` to generate `annotations_clean.json`.

## Requirements

- Python 3.7+
- [ultralytics](https://github.com/ultralytics/ultralytics) (for YOLO)
- pandas
- opencv-python
- matplotlib

## Notes

- Adjust paths in scripts if your directory structure differs.
- The number of categories after cleaning is saved in `src/count.txt`.
